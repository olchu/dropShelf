## Swift Development Skill
Этот проект — macOS-приложение на Swift + AppKit. При любой задаче связанной с разработкой используй скил `/swift-development`:
- Написание или рефакторинг Swift-кода
- Работа с AppKit, SwiftUI, Xcode
- Вопросы по архитектуре, concurrency, паттернам
- Сборка, тестирование, code signing
Вызов: `/swift-development` или ссылайся на него в контексте задачи.
