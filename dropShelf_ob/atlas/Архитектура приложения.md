# Архитектура приложения

DropShelf — macOS-приложение типа «status bar only», без окна в Dock.

## Компонентная схема

```
DropShelfApp (@main, SwiftUI)
└── AppDelegate (NSApplicationDelegate)
    ├── NSStatusItem          ← иконка в статус-баре
    ├── FloatingPanelWindow   ← NSPanel поверх всех окон
    │   └── ShelfViewController (NSViewController)
    │       ├── DropTargetView      ← фоновая зона приёма DnD
    │       ├── NSVisualEffectView  ← стеклянный blur-фон
    │       ├── NSTextField         ← заголовок "Drop files here"
    │       ├── OverlapStackView    ← стопка карточек + источник DnD
    │       │   └── FileItemView[]  ← превью файлов
    │       └── CloseButton         ← кнопка «×» с hover
    └── DragDetector          ← глобальный мониторинг мыши
```

## Поток данных при добавлении файла

1. Пользователь тащит файл → событие попадает в `DropTargetView` или `OverlapStackView`
2. Callback `onFilesDropped([URL])` → `ShelfViewController.addFile(url:)`
3. Создаётся `FileItemView(fileURL:)`, добавляется в `OverlapStackView`
4. `OverlapStackView.layout()` пересчитывает позиции и повороты карточек
5. Заголовок скрывается, стопка становится видимой

## Поток данных при извлечении файла

1. `mouseDown` в `OverlapStackView` → `beginGroupDrag(event:)`
2. Все `FileItemView` оборачиваются в `NSDraggingItem` (snapshot + frame)
3. `NSDraggingSession` запускается с `.pile` formation
4. `draggingSession(_:endedAt:operation:)` → если операция успешна → `onRemoveAll?()`
5. `ShelfViewController.clearAll()` очищает список и UI

## Поток отображения панели

- **Клик по иконке**: `toggleWindow()` в AppDelegate
- **Встряхивание мыши**: `DragDetector.onShakeDetected` → `AppDelegate.showWindow()`
- Позиция окна рассчитывается относительно кнопки статус-бара
