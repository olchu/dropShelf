# Стек технологий

## Языки и фреймворки

| Технология | Версия | Использование |
|-----------|--------|---------------|
| Swift | 5+ | Основной язык |
| SwiftUI | macOS 13+ | Только точка входа `DropShelfApp` |
| AppKit | macOS 13+ | Всё остальное: окна, вьюхи, DnD |
| Cocoa | — | `import Cocoa` во всех файлах кроме `DropShelfApp` |

## Используемые AppKit-компоненты

### Окна и панели
- `NSPanel` — floating window поверх обычных окон
- `NSStatusItem` / `NSStatusBar` — иконка в статус-баре
- `NSViewController` — контроллер содержимого панели

### Визуал
- `NSVisualEffectView` — blur-материал `.popover`
- `CALayer` — кастомный тёмный overlay, скругления, тени
- `NSImageView` — превью файлов
- `NSTextField` (label) — заголовок панели

### Drag & Drop
- `NSDraggingSource` — протокол источника drag (OverlapStackView)
- `NSDraggingDestination` — протокол цели drop (DropTargetView, OverlapStackView)
- `NSDraggingItem` — элемент drag-сессии с изображением
- `NSDraggingSession` — управление сессией перетаскивания
- `NSPasteboard` — чтение URL из буфера обмена

### События
- `NSEvent.addGlobalMonitorForEvents` — глобальный монитор событий мыши
- `NSTrackingArea` — hover-область для CloseButton

### Системные
- `NSWorkspace.shared.icon(forFile:)` — иконка файла из системы
- `NSImage(contentsOf:)` — предпросмотр изображений

## Требования

- **macOS**: 13.0 (Ventura) и выше
- **Xcode**: 14.0 и выше
- **Внешние зависимости**: отсутствуют (только Apple frameworks)

## Почему AppKit, а не чистый SwiftUI

SwiftUI в macOS 13 не даёт нужного контроля над:
- floating NSPanel с `.nonactivatingPanel`
- глобальными мониторами событий мыши
- точным управлением DnD с `NSDraggingItem`
- `NSVisualEffectView` с кастомными CALayer
