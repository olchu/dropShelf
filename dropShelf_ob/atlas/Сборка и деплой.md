# Сборка и деплой

## Локальная сборка

```bash
git clone <repository-url>
cd DropShelf
open DropShelf.xcodeproj
# ⌘R — запустить
```

## Конфигурация проекта

- **Bundle ID**: задаётся в `DropShelf.xcodeproj/project.pbxproj`
- **Deployment target**: macOS 13.0
- **Scheme**: DropShelf (единственная схема)
- **Signing**: требует Apple Developer аккаунт для дистрибуции

## Activation Policy

В `AppDelegate.applicationDidFinishLaunching`:
```swift
NSApplication.shared.setActivationPolicy(.accessory)
```
Это убирает приложение из Dock и из ⌘Tab. Иконка только в статус-баре.

## Assets

| Ассет | Назначение |
|-------|-----------|
| `AppIcon` | Иконка приложения (1024, 512, 256, 128, 64, 32, 16 px) |
| `StatusBarIcon` | Иконка в статус-баре (imageset, **не template**) |
| `statusbar` | Fallback-иконка статус-бара (PNG @1x, @2x, @3x) |

**Важно**: `button.image?.isTemplate = false` — отключает авто-перекраску системой. Цвет иконки сохраняется как есть.

## Потенциальная дистрибуция

- **Прямая**: собрать `.app`, заархивировать в `.dmg`
- **Mac App Store**: нужны entitlements, sandbox, notarization
- **Homebrew Cask**: возможно после notarization
