# Паттерн глобального мониторинга событий

Используется в `DragDetector` для отслеживания событий мыши из других приложений.

## Паттерн

```swift
class DragDetector {
    private var eventMonitor: Any?   // ← хранить ссылку!

    func startMonitoring() {
        eventMonitor = NSEvent.addGlobalMonitorForEvents(
            matching: [.leftMouseDragged]
        ) { [weak self] event in       // ← weak self обязательно
            self?.handleEvent(event)
        }
    }

    func stopMonitoring() {
        if let monitor = eventMonitor {
            NSEvent.removeMonitor(monitor)
            eventMonitor = nil         // ← обнулить
        }
    }
}
```

## Ключевые правила

1. **Хранить возвращаемое значение** — `addGlobalMonitorForEvents` возвращает `Any?`. Без сохранения монитор будет удалён сразу.

2. **`[weak self]` в замыкании** — монитор живёт дольше объекта. Без `weak` — retain cycle и утечка памяти.

3. **Вызывать `removeMonitor`** — мониторы не освобождаются автоматически. В DropShelf: `applicationWillTerminate` вызывает `dragDetector?.stopMonitoring()`.

4. **Global vs Local**:
   - `addGlobalMonitorForEvents` — события из других приложений (Finder)
   - `addLocalMonitorForEvents` — только своё приложение

## Когда использовать

- Когда нужно реагировать на действия пользователя в **другом** приложении
- Для «shake to show» паттернов
- Для глобальных горячих клавиш (лучше использовать Carbon hotkeys)

## Ограничения

- Требует `Privacy - Accessibility` entitlement для некоторых типов событий
- Не может **перехватить** или изменить событие (только наблюдать)
- Влияет на производительность при частых событиях (`.mouseMoved`)
