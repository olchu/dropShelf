# Продуктовая идея DropShelf

## Проблема

При работе с файлами в Finder часто нужно «отложить» файл, чтобы переключиться в другую папку, а потом вернуться к нему. Стандартные решения неудобны:
- Держать открытыми несколько окон Finder
- Перемещать на Рабочий стол как временное место
- Использовать Tags (требует настройки, не наглядно)

## Решение DropShelf

Плавающая панель-«полка» которая:
- Всегда поверх других окон
- Появляется при встряхивании мышью во время drag
- Принимает файлы drag & drop
- Возвращает файлы drag & drop в нужное место
- Исчезает из Dock, живёт в статус-баре

## Целевая аудитория

- macOS-пользователи, активно работающие с файлами в Finder
- Дизайнеры, фотографы, разработчики (частое перемещение файлов)
- Пользователи с одним монитором (нет места для второго окна Finder)

## Ключевой UX-момент

**Shake to show** — жест встряхивания мышью при drag — главная инновация. Не нужно:
- Отпускать файл
- Нажимать хоткей
- Кликать по иконке

Полка появляется в момент, когда пользователь уже держит файл.

## Конкуренты

- **Yoink** — платный (~$8), похожий concept, больше фич
- **Dropzone** — дороже, больше интеграций (cloud, apps)
- **Alfred** — file buffer в pro-версии
- **Finder Tabs** — встроено в macOS, но менее наглядно

## Потенциал монетизации

- Прямая продажа (единоразово, $5-10)
- Mac App Store
- Setapp (subscription bundle)

## Следующие шаги к продукту

- [ ] Персистентность файлов (сохраняются при перезапуске)
- [ ] Hotkey для показа/скрытия
- [ ] Максимальное количество файлов
- [ ] Настройки (размер панели, поведение)
- [ ] Notarization для дистрибуции
